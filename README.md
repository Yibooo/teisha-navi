# 定借ナビ

定期借地権マンションの資産価値を、過去の実取引データに基づいて第三者視点で可視化するWebサービス。

## サービス概要

- 残存年数別の資産価値推移をグラフで可視化
- 購入価格・残存年数・居住予定年数から将来価値をシミュレーション
- B2C（一般消費者）無料 + B2B（不動産事業者）有料の両手商売モデル

## 対象エリア

東京23区（MVP）

## 技術スタック

- **Frontend**: Next.js 15 (App Router)
- **Backend / DB**: Convex
- **Deployment**: Vercel
- **Charts**: Recharts
- **UI**: shadcn/ui + Tailwind CSS
