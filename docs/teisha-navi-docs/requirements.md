# 要件定義書

**サービス名**: 定借ナビ  
**バージョン**: 1.0  
**作成日**: 2026-05-11

---

## 1. サービス概要

| 項目 | 内容 |
|---|---|
| サービス名 | 定借ナビ |
| コンセプト | 定期借地権マンションの資産価値を実取引データで第三者視点から可視化するWebサービス |
| 対象エリア | 東京23区（MVP） → 首都圏 → 全国 |
| ビジネスモデル | B2C無料 + B2B有料（両手商売） |

## 2. 背景と課題

### 課題
東京では今後、定期借地権マンションの供給が増加する見込みである。しかし、不動産営業は自社利益が絡むため、購入者に対して第三者性を担保した説明が困難。

### 解決策
実取引データに基づく中立的な情報提供プラットフォームを構築し、購入者が数値データに基づいて意思決定できる環境を提供する。副次的に、不動産事業者の営業ツールとしても提供する。

---

## 3. ターゲットユーザー

### B2C（無料）
- 定期借地権マンションの購入・売却を検討している一般消費者
- ニーズ：「本当に買ってよいのか」「いつ売ればよいか」の客観的判断材料を求めている

### B2B（有料）
- 定期借地権マンションを販売・仲介する不動産会社・ディベロッパー
- ニーズ：顧客への説明ツール・営業資料・レポート自動生成・APIとしての組み込み

---

## 4. 機能要件

### 4.1 MVP機能（Phase 1）

#### F-01: 資産価値推移グラフ（コア機能）
- 残存年数別の成約価格（万円/m²）の散布図とトレンドライン
- 新築時価格を100%として、残存年数別の価格比率を表示
- フィルター条件
  - エリア（区単位）
  - 間取り（1LDK / 2LDK / 3LDK）
  - 専有面積帯（〜50m² / 50〜70m² / 70m²〜）
- データ件数・出典を画面上に明示

#### F-02: 資産価値シミュレーター
- **入力**
  - 購入価格（万円）
  - 現在の残存借地権年数（年）
  - 居住予定年数（年）
- **出力**
  - N年後の予測売却価格（万円）
  - 予測価格変動率（%）
  - グラフ上に現在位置と将来位置をプロット
  - 「売り時」推奨タイミング（価格下落が加速する閾値前）
  - 精度注記：「過去N件の取引データに基づく参考値」と明示

#### F-03: Admin（データ管理）
- 国交省APIからのデータインポート画面（単発実行ボタン）
- インポート済みデータの一覧・検索・編集
- 物件マスタ（定期借地権マンション一覧）の手動追加・編集フォーム

## 5. データ戦略

### 5.1 プライマリデータソース

#### 国土交通省 不動産取引価格情報API（メイン）
- URL: https://www.land.mlit.go.jp/webland/api.html
- 法的問題: なし（公開API・無料）
- 更新頻度: 四半期ごと
- 取得可能な主要フィールド
  - 取引価格、専有面積
  - 建築年、築年数
  - 土地の権利種類（借地権フラグ）
  - 最寄駅・徒歩分数
  - 区市町村、住所（一部）

#### 国土交通省 不動産情報ライブラリ
- URL: https://www.reinfolib.mlit.go.jp/
- 補完的に利用

### 5.2 データ品質担保戦略

国交省APIは「定期借地権」と「普通借地権」の区別、および残存年数の直接取得が困難。以下の手順でデータ品質を担保する。

```
Step 1: 国交省APIで東京23区の「借地権」フラグ付き取引を全件取得
Step 2: 既知の定期借地権マンションリスト（手動作成）と物件名・住所で照合
Step 3: マッチした取引のみを本サービスのデータとして採用
Step 4: 残存年数 = 借地権開始年 + 権利期間 - 取引年 で計算
         （物件マスタの借地権開始年・権利期間を手動で管理）
```

### 5.3 セカンダリデータ戦略（Phase 2以降）

- 不動産ポータルの公開情報（robots.txt 準拠・過負荷なし）
- **MVP期間はAPIおよび手動入力のみ**。スクレイピングは法的確認後に実施

### 5.4 データ収集フロー（MVP）

```
国交省API
    ↓ Convex Action（単発インポート）
Convex DB（transactions テーブル）
    ↓ 照合・エンリッチ処理
定期借地権物件マスタ（properties テーブル）
    ↓
analysisCache テーブル（グラフ・シミュレーション用集計済みデータ）
```

## 6. データモデル

### properties（物件マスタ）
```
id                  : ID
name                : string   // マンション名
ward                : string   // 区（例: 港区）
address             : string   // 住所
leaseStartYear      : number   // 借地権開始年
leaseTotalYears     : number   // 借地権総期間（例: 70年）
buildingYear        : number   // 建築年
totalUnits          : number   // 総戸数
nearestStation      : string   // 最寄駅
walkMinutes         : number   // 徒歩分数
notes               : string   // 備考
```

### transactions（取引履歴）
```
id                  : ID
propertyId          : ID       // properties への参照
transactionYearQ    : string   // 取引時期（例: 2023Q3）
price               : number   // 成約価格（万円）
areaSqm             : number   // 専有面積（m²）
floor               : number   // 階数
remainingLeaseYears : number   // 残存借地権年数（計算値）
pricePerSqm         : number   // 単価（万円/m²）
isNewConstruction   : boolean  // 新築フラグ
source              : string   // データソース
```

### analysisCache（グラフ・シミュレーション用集計キャッシュ）
```
id                  : ID
remainingYearsBucket: string   // 残存年数帯（例: 60-70, 50-60 ...）
ward                : string   // 区（null = 全区）
roomType            : string   // 間取り（null = 全タイプ）
avgPriceRatio       : number   // 新築比平均価格比率
medianPriceRatio    : number   // 新築比中央値価格比率
sampleCount         : number   // サンプル件数
updatedAt           : number   // 更新日時
```

## 10. リスクと対策

| リスク | 影響 | 対策 |
|---|---|---|
| 定期借地権の取引件数が少ない | グラフ精度低下 | サンプル数を明示・手動データ補完 |
| 残存年数の計算誤差 | シミュレーション精度低下 | 物件マスタを手動で精度管理 |
| 国交省APIでの物件名照合が困難 | データ件数減少 | 住所・築年・面積の複合条件で照合 |
| スクレイピングの法的リスク | 事業継続リスク | MVP期間はAPI＋手動のみ。Phase 2以降に法的確認後実施 |
