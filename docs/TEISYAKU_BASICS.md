## 1. 定期借地権とは

### 法的根拠

**借地借家法**（平成3年10月4日・法律第90号 / 平成4年8月1日施行）により創設。  
第22条に定める「**一般定期借地権**」が分譲マンションで最も多く用いられる。

### 旧法借地権との違い

| 項目 | 旧法借地権（大正10年〜） | 定期借地権（平成4年〜） |
|------|------------------------|----------------------|
| 更新 | 可能（原則） | **不可** |
| 存続期間 | 建物種類により30年〜 | **50年以上**（一般定期） |
| 建物買取請求 | あり | **なし** |
| 期間満了後 | 更新で継続 | **更地返還** |

### 定期借地権の3種類

| 種類 | 存続期間 | 主な用途 |
|------|---------|---------|
| 一般定期借地権（法22条） | 50年以上 | 分譲マンション・戸建て |
| 建物譲渡特約付借地権（法24条） | 30年以上 | 建物を地主に譲渡して終了 |
| 事業用定期借地権（法23条） | 10〜50年未満 | 店舗・商業施設 |

> 分譲マンションは原則「**一般定期借地権**」。最近は50〜75年の事例が多い。

## 2. 権利の種類：地上権 vs 賃借権

定期借地権付マンションの「敷地利用権」には2種類ある。

### 地上権（物権）

- 民法上の「物権」。借地人の**権利が強い**。
- **自由に譲渡・転貸可能**（地主の承諾不要が原則）
- 地上権自体に抵当権設定可能 → 住宅融資に有利
- **登記請求権あり** → 第三者対抗力が強い
- 流通性が高い借地権とされる

### 賃借権（債権）

- 民法上の「債権」。土地所有者との賃貸借契約。
- **譲渡・転貸には地主の承諾が必要**（承諾料が発生することも）
- 賃借権には登記請求権なし（地主の協力が必要）
- 転借地権（NTT東日本系物件等）は賃借権の一種

### 転借地権とは

事業者がまず土地を借り、そこに建てたマンションの購入者に「転貸」する形式。  
例：ウエリスシリーズ（NTT東日本の社宅跡地活用）、ジオ板橋大山（お茶の水女子大学用地）

## 3. 所有権マンションとの比較

### 権利構造の違い

| 項目 | 所有権マンション | 定期借地権付マンション |
|------|--------------|---------------------|
| 土地の権利 | 敷地所有権（共有持分） | 定期借地権（準共有） |
| 土地固都税 | 区分所有者が負担 | **地主が負担** |
| 地代 | なし | あり（月額） |
| 期間制限 | なし | あり（50〜75年が多い） |
| 更新 | 不要 | **不可** |
| 解体費用 | 将来必要（積立） | 解体準備積立金を毎月積立 |

### 分譲価格の水準

国土交通省「平成21年度 定期借地権付き住宅の供給調査」によると、  
**周辺所有権価格の約80%水準**が一般的な目安。  
（保証金・権利金・住宅価格の合計で比較）

| 周辺所有権比率 | 割合 |
|------------|------|
| 70%未満 | 約10% |
| 70〜80% | 約35% |
| 80〜90% | 約27% |
| 90%以上 | 約20% |

> **最近の傾向**: 好立地物件増加により分譲価格が上昇。周辺所有権と遜色ない価格帯も増加。

## 4. コスト構造

### 取得時コスト

| 費用 | 内容 | 特記事項 |
|------|------|---------|
| **分譲価格** | 建物価格 + 一時金 | 土地代は含まれない |
| **権利金** | 借地権設定対価 | 返還されない |
| **前払賃料** | 地代の前払い分 | 物件により分譲価格に含むケースあり |
| **保証金（敷金）** | 地代・義務履行の担保 | 期間満了時に返還（通例） |

> 近年は入札等により、権利金・前払賃料が**高額化**する傾向。一時金と地代のバランスが重要。

### 月々のランニングコスト

| 費用 | 目安 | 備考 |
|------|------|------|
| **地代（賃料）** | 数千円〜数万円/月 | 3年ごとに固都税連動で改定が多い |
| **解体準備積立金** | 数千円/月 | 管理組合が積立・保全 |
| 管理費 | 一般マンションと同様 | |
| 修繕積立金 | 一般マンションと同様 | |
| 建物固都税 | 建物部分のみ | 土地は地主負担 |

### 地代の改定方式（典型例）

```
改定地代 = 現行地代 × (改定年度の土地固都税額 ÷ 基準年度の土地固都税額)
```

- 改定差額が1万円未満の場合は据え置きとするケースが多い
- 3年ごと改定が主流（最初の改定は竣工後数年後）

## 5. 税金の違い

| 税金 | 所有権マンション | 定期借地権付マンション |
|------|--------------|---------------------|
| 消費税 | 建物価格に課税 | 建物価格に課税 |
| 不動産取得税 | 土地＋建物に課税 | **建物のみ**に課税 |
| 登録免許税（所有権移転） | 土地＋建物に課税 | **地上権・賃借権と建物**に課税（税率1/2軽減あり） |
| 登録免許税（抵当権） | 借入額に課税 | 借入額に課税（同様） |
| 固定資産税・都市計画税 | 土地＋建物に課税 | **建物のみ**に課税（土地は地主負担） |

> **ポイント**: 土地を所有しないため、各種税金が抑えられる。固都税は特に差が出る。

### 相続税評価

定期借地権の財産評価は、「自用地評価 × 定期借地権評価額 × 残存年数を反映した評価係数」で算出。  
詳細は税理士への確認が必要。

### 住宅ローン控除

- **適用可能**（建物・借地権部分のローン）
- ただし、前払賃料相当分の借り入れには住宅ローン控除が適用されない場合がある
- 適用条件・時期の詳細は最新の国税庁通達を確認すること

## 6. 住宅ローン・融資

- **フラット35** 利用可能
- 提携銀行ローン 利用可能
- **地上権**付き物件は、地上権自体に抵当権設定可能 → 融資条件に有利
- **賃借権**付き物件は、前払賃料返還請求権への質権設定が融資条件となるのが通例
- 中古取引時も住宅ローン利用可能（金融機関により条件異なる）

## 7. 期間満了時の取り扱い

### 原則

1. **建物を解体**して更地にして地主に返還
2. 建物の買取請求・契約更新・期間延長は**一切不可**
3. 解体費用は管理組合の**解体準備積立金**から充当

### 解体積立金の保全

- 管理組合が積み立て
- 定期借地権設定契約で質権設定（担保）を規定するケースが多い
- 地主・管理組合・区分所有者全員が連帯して原状回復義務を負う

### 期間内解約

- 区分所有者全員（または管理組合）が地主に解約申入れ
- 申入れから終了まで1年以内が一般的
- 解体・更地化が条件

## 8. 供給状況・市場トレンド

### 全国供給推移（マンション）

| 年代 | 概況 |
|------|------|
| 平成5〜10年 | 創設期。試行錯誤の段階。 |
| 平成11〜20年 | 年間500〜2,000戸規模で増加。 |
| 平成21年以降 | 累計2万9千戸超（マンションのみ）。 |
| 近年 | 好立地の高額物件が増加。NTT系・学校法人系の大規模開発が目立つ。 |

### 最近のトレンド

- **借地期間の長期化**: 60〜75年が主流に（30〜40代購入者の不安に対応）
- **地上権が主流**: 流通性・融資面での優位から
- **保証金の減少**: 一時金構成の変化（権利金重視）
- **好立地集中**: フランス大使館跡（プラウド南麻布）、日赤医療センター（広尾ガーデンフォレスト）、渋谷区有地（パークコート渋谷ザタワー）など
- **大学・NTT系**: お茶の水女子大学（ジオ板橋大山）、NTT東日本（ウエリスシリーズ）

- **地主**: フランス大使館旧館跡地
- **概要**: 荘厳な森に抱かれた希少物件。野村不動産開発。
- **特徴**: 定期借地権を活用した施設再生の好例。

### パークコート渋谷ザタワー（渋谷区）
- **概要**: 渋谷区有地。公共施設の建替えに寄与。地上39階。
- **存続期間**: 約70年（〜2093年9月）
- **特徴**: 地代を販売価格に一括含む方式。

### タンタタウン港北ニュータウン（横浜市）
- **地主**: 相模鉄道ほか
- **概要**: 678戸の大規模開発。100m²台中心の広い専有面積。
- **特徴**: 相鉄不動産初の定期借地権物件。

### 藤和田園調布ホームズ（1995年分譲）
- **概要**: 都内初の定期借地権付マンション分譲。
- **特徴**: 平均倍率10倍超で即日完売。その後の定借マンション開発のお手本に。

## 10. よくある質問Q&A

### Q1. なぜ定期借地権マンションなのですか？
**A.** 地主が土地を手放さずに活用するため。好立地の土地（学校法人・NTT社宅跡地・公共施設跡地など）が供給されやすく、結果的に購入者も好立地・低コストで取得できます。

### Q2. 住宅ローンは使えますか？
**A.** はい、フラット35・提携銀行ローンともに利用できます。地上権付き物件は地上権自体に抵当権設定が可能で融資条件に有利です。

### Q3. 将来、中古で売れますか？
**A.** 売却可能です。地上権は承諾不要で自由に譲渡できます（賃借権は地主への通知・承諾が必要）。残存年数が長いほど流通性は高い傾向があります。

### Q4. 地代は上がることがありますか？
**A.** 一般的に3年ごとに固定資産税・都市計画税の増減に連動して改定されます。大幅な値上げを防ぐ仕組みが契約書に規定されています。

### Q5. 期間満了後はどうなりますか？
**A.** 建物を解体して更地にして地主に返還します。解体費用は毎月の解体準備積立金で賄います。建物の買取請求・更新は一切できません。

### Q6. 賃貸に出すことはできますか？
**A.** 可能です。ただし賃貸借契約は定期借地権の存続期間内に終了するよう設定する必要があります。残存期間が10年以下になった場合は特別な手続きが必要です。

### Q7. 相続はできますか？
**A.** 可能です。相続した場合は地主への通知が必要なのが一般的です。相続税評価は自用地評価に定期借地権評価・残存年数を反映して算出します。

### Q8. 地代を払わないとどうなりますか？
**A.** 地代不払いは契約違反となり、最終的に借地権が消滅する可能性があります。他の区分所有者が不払いの場合、管理組合や地主が対処する仕組みが通常設けられています。

### Q9. 地主が変わることはありますか？
**A.** あります。ただし、地主が変わっても定期借地権設定契約の内容は引き継がれます（登記されている場合は第三者対抗力あり）。

### Q10. 所有権マンションと比べてデメリットは？
**A.** ①期間満了後は返還が必要（永住不可）、②毎月地代・解体積立金の負担がある、③残存年数が短くなると資産価値が低下しやすい、④一部金融機関で融資が難しい場合がある、の4点が主なデメリットです。

## 11. 営業のポイント（不動産担当者向け）

### 基本姿勢

- 「定期借地権設定契約書」「確認合意書」が**いわば憲法**。参照しながら分かりやすく説明する
- 不明な点は必ず社内確認してから回答（誤情報はNG）
- お客様が心配している理由を**明確にする**。漠然とした「定期借地権だから…」を論拠にさせない

### お客様が本物件を選ぶ理由を把握する

```
予算 / 立地 / 間取り / 利便性 / 学区 / 地縁
```

立地と予算がマッチすれば成約の可能性あり。心配を解消すれば成約に繋がる。

### よくある反対理由と対応

| 反対理由 | 対応のポイント |
|---------|-------------|
| 「借地権が不安」 | 旧法借地権との違いを明確に。法的安定性を説明。 |
| 「地代が不安」 | 改定の仕組み・計算式を提示。固都税連動で安定的。 |
| 「将来売れるか不安」 | 中古取引事例を提示。残存年数が長い間は流通性あり。 |
| 「周囲に反対された」 | 周囲の反対はほぼ「知識不足」。情報を提供して解消。 |
| 「競合物件の営業に否定された」 | 比較資料で冷静に説明。感情的にならない。 |

### 準備すべき資料・情報

- [ ] 定期借地権設定契約書・確認合意書
- [ ] 中古取引事例データ（残存年数別）
- [ ] 周辺所有権物件との価格比較
- [ ] 住宅ローン融資確認（提携金融機関リスト）
- [ ] 相続・売却時の手続きフロー
- [ ] 解体積立金の積立計画
