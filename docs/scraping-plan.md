_作成日: 2026-05-18_

---

## 1. 市場全体像

東京都の定期借地権マンションストック（2022年12月末時点）:
- **122棟・11,263戸**（全国ストックの33%）
- 集中エリア: 千代田区・港区・渋谷区・新宿区
- 借地期間: 1990〜2000年代物件は50年台、2010年代以降は70年以上が標準

## 3. 取得データの種類（3ステップ）

各物件につき、以下3種類の価格データを収集・格納します。

| ステップ | データ種別 | priceType | 取得方法 |
|---------|-----------|-----------|---------|
| STEP 1 | 新築売り出し価格 | `new_construction` | マンションDB・旧販売サイト・不動産ブログ |
| STEP 2 | 中古売り出し価格 | `listing` | SUUMO・東急リバブル・野村不動産アーバンネット |
| STEP 3 | 実際の成約価格 | `transaction` | 国交省CSV（手動DL）または管理者画面から手動入力 |

---

## 4. スクレイピング手法

### STEP 1: 新築価格取得

優先ソース（順番に試す）:
1. **マンションDB** (`https://mansion-db.com/`) - 新築分譲時の価格テーブル
2. **SUUMO 物件詳細**（過去物件ページ）
3. **不動産情報ブログ**（のらえもんブログ等） - 大型物件の価格分析記事
4. **公式サイトキャッシュ** - Wayback Machine等

取得項目:
- 最多価格帯
- 最低・最高価格
- 代表的な住戸の専有面積・坪単価

### STEP 2: 中古売り出し価格取得

SUUMOキーワード検索URL:
```
https://suumo.jp/jj/bukken/ichiran/JJ010FJ001/?ar=030&bs=011&ta=13&kb=1&mb=0&et=9999999&cn=9999999&shkr1=03&shkr2=03&shkr3=03&shkr4=03&skb=0&smb=0&kw=<物件名>
```

取得項目:
- 売り出し価格
- 専有面積
- 売り出し時期（取引時期の近似値）
- 残存年数（計算: 期限年 - 現在年）

### STEP 3: 成約価格（将来）

- 国交省 土地総合情報システム CSV（手動ダウンロード）
- 管理者画面（`/admin/import`）からCSVアップロード
- または管理者が個別物件ページから手動入力

## 5. スキーマ設計変更

### `transactions` テーブルへの追加フィールド

```typescript
priceType: v.optional(v.union(
  v.literal("new_construction"),  // 新築売り出し価格
  v.literal("listing"),           // 中古売り出し価格（SUUMO等）
  v.literal("transaction"),       // 実際の成約価格（国交省等）
))
```

- `isNewConstruction: true` → `priceType: "new_construction"` と等価
- 既存データとの後方互換性を維持（optionalフィールド）

## 7. 注意事項

- SUUMOスクレイピングは利用規約の範囲内で実施（個人利用・研究目的）
- 大量リクエストは避け、物件単位で間隔を空ける
- データソース（URL）を必ず `source` フィールドに記録する
- 価格データは「参考情報」として提示し、投資助言にならないよう注意書きを表示する
